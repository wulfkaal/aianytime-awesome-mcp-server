Fax for Agents

Send and receive faxes from an AI agent: prepare a document, get a quote, send, poll for the carrier's evidence, read inbound faxes. Bearer API key, a test key is free and uses a sandbox with no carrier. Endpoint: https://mcp.faxforagents.com/mcp/ · Docs · Registry: io.github.faxforagents/faxforagents-mcp

Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http fax-for-agents https://mcp.faxforagents.com/mcp/

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://mcp.faxforagents.com/mcp/

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "fax-for-agents": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.faxforagents.com/mcp/"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "fax-for-agents": {
      "url": "https://mcp.faxforagents.com/mcp/"
    }
  }
}

VS Code

Or add it to .vscode/mcp.json:

    "fax-for-agents": {
      "type": "http",

code --add-mcp '{"name": "fax-for-agents", "type": "http", "url": "https://mcp.faxforagents.com/mcp/"}'

{

      "type": "http",

}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

Read a received fax (inbox_item_id) or a document (document_id) with OCR and, with a schema (a JSON Schema object of string, number, boolean or date fields), extract those fields with page citations and confidence. send_approved_faxcan modifydestructiveexternal accessQueue a quoted fax. A quote with authorization_required=false sends as is; otherwise pass the approval_id of …

Queue a quoted fax. A quote with authorization_required=false sends as is; otherwise pass the approval_id of an approved request bound to this quote (request_human_review), or send under a delegated policy that allows it. Repeat with the same idempotency_key to get the same fax back. The answer is queued, never delivered: poll get_fax_status. Scope: fax:send.
